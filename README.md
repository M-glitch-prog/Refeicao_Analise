# 📊 Análise de Refeições Escolares# 📊 Análise de Refeições Escolares
Projeto introdutório de Ciência de Dados desenvolvido em Python para analisar dados fictícios de consumo de refeições escolares.

## 🎯 Objetivo
Analisar padrões de consumo, repetições, refeições e desperdício, utilizando dados armazenados em uma planilha Excel.

## 🛠️ Tecnologias utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Excel

## 📚 Conceitos praticados
- Importação de dados
- DataFrames
- Análise exploratória
- Filtros
- Agrupamento de dados (`groupby`)
- Estatísticas básicas
- Manipulação de planilhas
- Visualização de dados
## Observação!
Os dados utilizados neste projeto são fictícios e foram criados exclusivamente para fins educacionais.
